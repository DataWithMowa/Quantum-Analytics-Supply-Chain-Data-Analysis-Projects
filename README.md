# Quantum-Analytics-Supply-Chain-Data-Analysis-Projects

A collection of supply chain-focused data analytics projects done with Quantum Analytics, covering beauty retail logistics and greenhouse gas emissions trends. Built with Excel and Power BI to turn supply chain data into clear, actionable insights.

---

## 📁 Projects in This Repository

### 💄 [Glow Supply Chain Excel Project](https://github.com/DataWithMowa/Quantum-Analytics-Supply-Chain-Data-Analysis-Projects/tree/main/Glow%20Supply%20Chain%20Excel%20Project)
An Excel analysis of Glow Fashion & Beauty Store's supply chain — 100 products tracked across 5 Indian cities, revealing which product category, carrier, and transport mode actually drive revenue versus risk.

### 🌍 [Supply Chain Greenhouse Gas Emissions Power BI Project](https://github.com/DataWithMowa/Quantum-Analytics-Supply-Chain-Data-Analysis-Projects/tree/main/Supply%20Chain%20Green%20house%20Gas%20Emissions%20Power%20BI%20Project)
A Power BI dashboard built on the EPA's Supply Chain GHG Emission Factors dataset — 1,016 NAICS sectors grouped into 18 industries, to see which sectors and industries carry the heaviest greenhouse gas footprint per dollar.

---

## 🛠️ Tools Used

Excel · Power BI · Power Query · DAX
